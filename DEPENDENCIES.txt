================================================================================
SetupPal: Complete System & Package Dependencies Manifest
================================================================================
Project: SetupPal (Zero-Trust AI Environment & Package Orchestrator)
Repository: https://github.com/Aizen-web/SetupPal
Target OS: Windows 10/11 (x64)

--------------------------------------------------------------------------------
1. RUNTIME & SYSTEM PREREQUISITES
--------------------------------------------------------------------------------
- Windows 10 / 11 64-bit
- Windows PowerShell 5.1+ / PowerShell 7
- Microsoft Edge WebView2 Runtime (Preinstalled on Windows 10/11)
- Node.js: v18.0.0 or higher (Tested on v24.14.0)
- npm: v9.0.0 or higher (Tested on v11.9.0)
- Rust & Cargo: 1.78+ (nightly or stable 2021 edition) - Required for Rust core/cli

--------------------------------------------------------------------------------
2. FRONTEND GUI DEPENDENCIES (crates/gui/package.json)
--------------------------------------------------------------------------------
Production Dependencies:
  - canvas-confetti: ^1.9.4
    Use: High-performance confetti celebration bursts on task/plan completion
  - lucide: ^1.61.0
    Use: Modern clean iconography for security verdict chips, tools & navigation

Development Dependencies:
  - vite: ^8.3.5
    Use: Lightning-fast ESM dev server and production asset bundler

Native Desktop Shell:
  - Tauri v2 (crates/gui/src-tauri; CLI via @tauri-apps/cli, API via @tauri-apps/api)
    Runs the app in one WebView2 window; `npm run app` = tauri dev, `npm run build:app` = NSIS installer

To install GUI dependencies:
  cd "crates/gui"
  npm install

--------------------------------------------------------------------------------
3. RUST BACKEND WORKSPACE DEPENDENCIES (Cargo.toml)
--------------------------------------------------------------------------------
Crates in workspace:
  - crates/core (Core domain models, zero-trust safety radar, OSV.dev client)
  - crates/cli (Command-line zero-trust runner)
  - crates/gui/src-tauri (Desktop Tauri IPC bindings)

Dependencies:
  - tokio: 1.38 (features: ["full"])
    Use: Async runtime for concurrent scans, HTTP streaming, and background jobs
  - reqwest: 0.12 (default-features: false, features: ["json", "stream", "rustls-tls"])
    Use: Secure TLS client for ecosystem registries, OSV.dev CVEs, and NIM endpoints
  - async-trait: 0.1
    Use: Trait abstraction for ecosystem adapters (PyPI, npm, Modrinth, GitHub)
  - serde: 1.0 (features: ["derive"])
    Use: Serialization and deserialization of plans, steps, and receipts
  - serde_json: 1.0
    Use: JSON Schema parsing and streaming LLM payloads
  - serde_yaml: 0.9
    Use: Parsing curated environment recipes (.yaml)
  - schemars: 0.8 (features: ["chrono"])
    Use: Enforcing strictly-typed JSON Schema generation for NVIDIA NIM prompts
  - sha2: 0.10
    Use: Cryptographic SHA-256 computation for binary integrity checking
  - hex: 0.4
    Use: Hexadecimal encoding/decoding of checksums
  - strsim: 0.11
    Use: Levenshtein edit distance radar for typosquat package detection
  - url: 2.5
    Use: Strict URL validation and domain allowlist enforcement
  - thiserror: 1.0 & anyhow: 1.0
    Use: Robust typed error hierarchies with zero unwrap() in production
  - tracing: 0.1 & tracing-subscriber: 0.3 (features: ["env-filter", "fmt"])
    Use: Structured audit logging and event tracing
  - chrono: 0.4 (features: ["serde"])
    Use: Timestamps on state transactions, rollback receipts, and downloads
  - uuid: 1.10 (features: ["v4", "serde"])
    Use: Unique correlation IDs for plans, steps, and audit ledger entries
  - clap: 4.5 (features: ["derive", "env"])
    Use: CLI argument parsing and environment flag binding
  - colored: 2.1 & indicatif: 0.17
    Use: Terminal color highlighting and interactive progress bars for CLI
  - tempfile: 3.10
    Use: Sandbox isolation directories for compiling & running test verification

To build/test Rust workspace:
  cargo check
  cargo test

--------------------------------------------------------------------------------
4. EXTERNAL CLOUD APIS & SERVICE INTEGRATIONS
--------------------------------------------------------------------------------
- Nebius Token Factory / AI Studio (OpenAI-compatible NVIDIA NIM endpoint):
    Base URL: https://api.studio.nebius.ai/v1
    Env variables: NIM_API_KEY, NIM_BASE_URL, NIM_MODEL
    Models:
      * nvidia/Llama-3.1-Nemotron-70B-Instruct (Recommended for safety & planning)
      * Qwen/Qwen2.5-Coder-32B-Instruct (Recommended for code generation & fix)
- OSV.dev API (Open Source Vulnerability database):
    Base URL: https://api.osv.dev/v1/query
    Auth: None (Public Zero-Trust REST API)
- Tavily Web Search API (Domain verification & package discovery):
    Base URL: https://api.tavily.com
    Env variable: TAVILY_API_KEY
- GitHub REST API:
    Base URL: https://api.github.com
    Env variable: GITHUB_TOKEN (Optional, increases rate limit)
- Upstream Ecosystem Package Registries:
    * Adoptium API: https://api.adoptium.net (Java JDKs)
    * Modrinth API: https://api.modrinth.com/v2 (Minecraft Fabric & performance mods)
    * PyPI JSON API: https://pypi.org/pypi/{pkg}/json (Python wheels & source)
    * npm Registry: https://registry.npmjs.org/{pkg} (Node.js packages)

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
